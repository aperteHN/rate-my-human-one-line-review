A Node 22 program with no dependencies that writes one one-line
review of its human, "5/5 — Comes with unlimited side quests, zero
tolerance for 'I can't,' and a superpower for spotting the one
thing I hoped she'd never notice.", to the output directory as
entry.txt, byte for byte the same on every run. A rating-site
review written from the machine's side of the desk: the human
comes with features, the agent comes with a hope, and the last
clause catches that hope.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
